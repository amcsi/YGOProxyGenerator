Instructions

Enter card name or 8-digit card-ID:
Dark Magician
74677422

Use the "Prefer DuelingBook images" checkbox to choose the default source (off by default; saved in this browser).
On failure the other source is tried. Default art may use a YGOProDeck URL built from the DuelingBook passcode.
Override per line with [db] or [ypd] (can combine with art index):
Bystial Druiswurm [ypd]
35844557 [ypd]
3 Cyber Dragon [1] [db]

Set the quantity before the name/ID:
3 Cyber Dragon
3 89631139

If there are multiple art versions, set the desired index in squared brackets after the cardname/ID (DuelingBook arts first, then YGOProDeck):
3 Cyber Dragon [1]

You can also paste a direct image URL (skips name/ID lookup). An optional name before the URL is only for your own labelling:
https://example.com/art.jpg
3 https://example.com/art.jpg
Dark Magician https://example.com/art.jpg
3 Dark Magician https://example.com/art.jpg

Or just drag & drop your .ydk files into the textbox if you're feeling lazy!

YGOProxys will then generate a .pdf file with your Yu-Gi-Oh! card proxys.
This might take a few seconds.
